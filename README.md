# 杯中世界

个人兴趣读本，主题为酒、茶、咖啡的起源、发展、制作与风味。

## 成书原则

- 以短章连接历史、工艺与日常体验；不作品牌排名、价格推荐或资格考试教材。
- 酒类占主要篇幅，茶与咖啡各有完整入门章节，并通过风味、加工与文化形成共同线索。
- 考古证据与传说分开，现代商品类别不倒推到史前饮品。
- 文中资料编号对应当页页下注；页下注列机构、题名或短题名、可点击原文链接；书末列完整目录与检索日期。
- 自拟实验、类比与判断明确注明，不包装为引用来源的结论。
- AI 插画仅营造阅读情境；精确分类和流程使用人工定义的矢量图。

## 结构

1. 共同基础：三类饮品的相似与差异、感官、早期历史。
2. 酒：啤酒、葡萄酒、气泡与加强酒、黄酒与清酒、白酒、威士忌、白兰地与朗姆、金酒伏特加龙舌兰、调饮。
3. 茶：历史、六大茶类、冲泡。
4. 咖啡：历史与品种、处理与烘焙、冲煮。
5. 带回日常：储存、标签与预算、饮用边界、个人笔记。

## 文件

`chapters/` 为按章拆分的可编辑稿件；`research/sources.json` 为参考资料；`build_book.py` 为排版程序；`assets/` 为插画和字体；`output/` 为成品。

Git 按规划、正文、插画排版、校订交付分阶段提交。仓库为本地版本管理，不预设远程仓库。

## 重建

使用 Python，依赖 reportlab、fonttools、Pillow、pypdf。在项目目录运行 `python build_book.py`。PDF 为 A5 阅读开本，字体嵌入，页码连续，目录与书签可导航。
