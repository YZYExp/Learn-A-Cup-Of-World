我们常说的绿茶、白茶、黄茶、乌龙、红茶与黑茶，主要围绕茶树叶子的加工差异形成。联合国教科文组织对中国制茶传统的介绍也列出了这六类。[31] 名字中的颜色是提示，不能仅靠一杯茶汤的颜色完成分类。

茶加工里一个重要问题是：怎样让叶子继续变化，或者怎样在合适时刻把某些变化停下来。杀青、萎凋、揉捻、氧化、焙火和干燥，各自承担不同作用；不同茶类并不是把完全相同流程做得长一点或短一点。[34]

绿茶通常较早通过热处理控制相关酶活动。红茶则利用明显的酶促氧化改变叶中成分。乌龙在氧化和其他加工选择上形成不同风格。[34] 因此，把所有茶排成“发酵从少到多”的一条直线，会漏掉不少工序。

| 茶类|入门观察方向 |
| --- | --- |
| 绿茶|较早控制酶相关变化 |
| 白茶 黄茶|分别关注萎凋干燥与闷黄 |
| 乌龙 红茶|关注氧化与其他工序的安排 |
| 黑茶|关注微生物相关加工过程 |

这张图只用于比较主要方向，不是完整工艺路线。每一类内部仍有原料、地区与手法差别。

本书建议先从熟悉的茶倒推：你喝到的清鲜、烘烤或浓厚印象，有没有可能与加工有关？等你能问出这个问题，再记名字会容易得多。

## 白茶 黄茶 黑茶与花茶

白茶常以萎凋和干燥为重要加工环节；黄茶的闷黄，又让它与绿茶等形成区别。黑茶中的微生物相关过程，与红茶核心的酶促氧化也不是一回事。[34] 入门阶段不必追求精确“发酵百分比”，先识别改变叶子的方式。

本书的阅读提醒是：别把低加工想成没有加工，也别把加工多想成更高级。不同路线是在形成不同饮用体验，没有义务按同一把尺排序。

还有一个语言上的小坑。中文“红茶”通常对应英文 black tea；中文“黑茶”则需要另行理解，不能逐字翻译后当成同一种东西。跨语言读资料时，最好同时看茶名和制作说明。[34]

花茶也需要拆开。以茶叶为底、经过窨花等再加工的茶，与单纯把花或草本泡水，不是同一种原料类别。UNESCO 的资料把花香再加工茶放在六类基础茶之外进一步介绍。[31]

**本书建议的文字练习。** 从一份茶叶标签中找三项：茶类、具体名称、有没有额外香料或窨制说明。若写着茉莉香，再问它是茶叶本身带来的印象，还是生产中引入了花香。没有信息时就不猜。

茶的名字可以很多，但你的基础问题只要几个。茶类负责缩小范围，加工负责解释差异，最后仍由实际茶汤和个人感知告诉你喜欢什么。
